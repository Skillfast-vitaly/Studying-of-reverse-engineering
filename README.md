# Реверс-инжиниринг с нуля

Курс для тех, кто начинает с полного нуля: без опыта программирования, без
знания ассемблера, без английского выше школьного.

**Цель курса** — научиться брать незнакомую программу Windows (файл `.exe`)
и понимать, что у неё внутри и как она работает.

---

## Для кого это

- Опыт программирования: **не требуется**
- Знание английского: **A2 и выше хватит** — все термины даются с переводом,
  есть [словарь](GLOSSARY.md)
- Математика: **школьной достаточно**
- Система: **Windows 10 или 11** с правами администратора
- Темп: **1–2 часа в день**, курс рассчитан примерно на 4–6 месяцев

## 🔢 Интерактивный тренажёр

**[Открыть тренажёр](https://claude.ai/artifact/2UULEnh9wsTTKAgk9So5Xf)**

Чтение — пассивно, и через день из головы выветривается. Навыки, которые
нужны в реверсе каждую секунду, доводят до автоматизма тренировкой:

- перевод **HEX ↔ DEC** в обе стороны
- **порядок байтов** — переворот little-endian
- **ASCII** — чтение байтов как текста
- **знаковые числа** — дополнительный код
- **английские термины** — карточки к словарю

И проверка понимания **по каждой написанной главе**: сверху кнопки глав
(0–2, 3, 4–5, 6–8, 9–12, 13–15, 16, 17, 18, 20, П1–П7, 26, 27, 28, 29, 30, 32, 33, 34, 40), под ними режимы этой главы
и «Всё вперемешку». Кнопка «все» — экзамен вперемешку по всему курсу.
В конце каждой главы написано, какой режим к ней относится.

Каждая ошибка разбирается по шагам, а не просто отмечается красным.
Открывается с телефона, прогресс сохраняется.

## Как пользоваться

1. Главы идут строго по порядку — каждая опирается на предыдущие.
2. Все команды и действия **повторяй руками**. Чтение без практики здесь
   не работает совсем.
3. В конце каждой главы — упражнения. Они не для галочки, ответы нужны дальше.
4. Разборы задач (главы 16–20) — это спойлеры. Не открывай, пока не помучился
   сам хотя бы час.

Непонятное слово — сначала в [словарь](GLOSSARY.md), там все термины
с русским объяснением и английским оригиналом.

## Курс у тебя на ПК

С макбука удобно читать и писать мне в чат. А на ПК с Windows курс
работает полностью: навыки, сводка в начале сессии, подсказчик,
Наставник IDA. И главное — там я могу **запускать** программы курса
по-настоящему, а в облаке нельзя.

Поставить один раз (сверено по документации 10.10.2026):

1. **Git for Windows** — [git-scm.com/downloads/win](https://git-scm.com/downloads/win).
   Через его оболочку Git Bash Claude Code выполняет команды.
2. **Python 3.13** — нужен и IDA (для плагинов), и скриптам курса.
   Поставь **Python Install Manager** (найди его в Microsoft Store или
   скачай с [python.org](https://www.python.org/downloads/)), потом
   в PowerShell: `py install 3.13`. Если спросит про PATH (список
   папок, где Windows ищет программы) — соглашайся. Именно 3.13:
   IDA 9.2 понимает Python 3.11–3.13, более новый с ней не заработает.
   Подробно — [приложение П6](course/p6-python.md), раздел П6.2.
3. **Claude Code** — в PowerShell (синее окно; найди его через «Пуск»):

   ```
   irm https://claude.ai/install.ps1 | iex
   ```

   Или приложение Claude для Windows с claude.com/download.

Забрать курс и открыть. Если в главе 6 ты уже склонировал его через Git
в `C:\reverse\course`, просто обнови его (`pull` — «подтянуть»):

```
cd C:\reverse\course
git pull
claude
```

Если курса там ещё нет или ты скачивал его архивом ZIP, склонируй
заново. Старую папку из архива сначала переименуй, например
в `course-old`, иначе Git откажется писать в непустую папку:

```
git clone https://github.com/Skillfast-vitaly/Studying-of-reverse-engineering C:\reverse\course
cd C:\reverse\course
claude
```

При первом запуске Claude Code спросит, доверяешь ли ты этой папке.
Соглашайся: это твой курс, без доверия не включатся его настройки.
Дальше просто напиши «привет». Я сам найду свежую версию курса и спрошу,
где ты. Отметки о занятиях на ПК я сохраняю в `PROGRESS.md`
и отправляю на GitHub, так что в облаке их тоже будет видно.

## Глубокий трек: дорога к гипервизору

Дальше — путь для тех, кто хочет не просто «понимать `.exe`», а спуститься
до самого низа, к ядру и железу. **Это твоя цель.** Каждая часть — этаж,
и пропустить нельзя: без страничной памяти не будет гипервизора, без
драйверов не будет отладки ядра.

> ▶ **Порядок прохождения — не по номерам.** 26 → 27 → 28 →
> **32 → 33 → 34** (часть X) → **29 → 30** (часть IX). Драйвер
> из главы 29 и отладчик ядра из главы 30 опираются на архитектуру
> процессора из части X, а части X хватает глав 26–28. Приложения:
> П1 — до части IX, П3 — после главы 26 и П1, П2 и П4 — перед частью XI.
> Глава 31 и главы 35–39 пока не написаны.
