# Реверс-инжиниринг с нуля

Курс для тех, кто начинает с полного нуля: без опыта программирования, без
знания ассемблера, без английского выше школьного.

**Цель курса** — научиться брать незнакомую программу Windows (файл `.exe`)
и понимать, что у неё внутри и как она работает.

---

## Для кого это

- Опыт программирования: **не требуется**
- Знание английского: **A2 и выше хватит** — все термины даются с переводом,
  есть [словарь](GLOSSARY.md)
- Математика: **школьной достаточно**
- Система: **Windows 10 или 11** с правами администратора
- Темп: **1–2 часа в день**, курс рассчитан примерно на 4–6 месяцев

## Как пользоваться

1. Главы идут строго по порядку — каждая опирается на предыдущие.
2. Все команды и действия **повторяй руками**. Чтение без практики здесь
   не работает совсем.
3. В конце каждой главы — упражнения. Они не для галочки, ответы нужны дальше.
4. Разборы задач (главы 16–20) — это спойлеры. Не открывай, пока не помучился
   сам хотя бы час.

Непонятное слово — сначала в [словарь](GLOSSARY.md), там все термины
с русским объяснением и английским оригиналом.

## Правовая рамка

Всё, что разбирается в этом курсе, **написано специально для курса**.
Ты разбираешь собственные программы — это законно везде.

Навык, который ты получишь, применим и к чужому софту. Границы описаны
в [главе 0](course/00-vvedenie.md#04-закон-и-этика--прочитай-это-важно).
Короткая версия: ломай только то, что принадлежит тебе или что тебе явно
разрешили ломать.
