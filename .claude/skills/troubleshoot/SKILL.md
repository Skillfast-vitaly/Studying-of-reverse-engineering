# Когда что-то не работает

Техническая заминка убивает силы быстрее трудной темы, а перегорание —
главный риск этого ученика (`CLAUDE.md`, раздел 1). К тому же сообщения
об ошибках написаны по-английски, а у него A2. Поэтому сначала
успокоить, потом разобраться, по одному шагу.

## 1. Сначала спокойствие

Одной фразой: это обычное дело, у всех так бывает, разберёмся. Не «ты
что-то сделал не так».

## 2. Факты, а не догадки

Спроси в одном сообщении, не больше четырёх вопросов:

1. **точный текст ошибки** — скопировать или прислать скриншот,
   а не пересказ;
2. **что делал** по шагам: какую команду ввёл, какую кнопку нажал;
3. **где:** редакция Windows (Win+R → `winver`), какой из двух ПК
   (Ryzen или Intel);
4. **версия инструмента** (обычно Help → About, «Справка → О программе»).

## 3. Перевести ошибку

Переведи сообщение по словам и объясни смысл простыми словами. Для A2
это половина решения: часто ошибка прямо говорит, что не так.

## 4. Частые причины в этом курсе

| Что видит | Частая причина | Где в курсе |
|---|---|---|
| `gcc: command not found` | запущен обычный `cmd`, а не консоль w64devkit | глава 6 |
| своя программа не запускается по имени | в w64devkit оболочка `sh`: запуск через `./имя.exe`, пути через `/` | глава 6 |
| кракозябры вместо русских букв | кириллица в строках программы — пиши транслитом | `crackmes/` |
| «Windows protected your PC» («Система Windows защитила ваш компьютер») на своём `.exe` | SmartScreen не знает новый файл: «More info» («Подробнее») → «Run anyway» («Выполнить в любом случае»), только для своих программ | в главах нет: встретится — добавь в главу 6 |
| Ghidra не стартует | нет JDK нужной версии | главы 6, 14 |
| точка останова не срабатывает по адресу из главы | ASLR: адреса другие, ищи по RVA | главы 13, 16 |
| Process Monitor «завален» событиями | нужен фильтр по имени процесса | глава 15 |
| виртуальная машина не создаётся | виртуализация выключена в BIOS (Диспетчер задач → Производительность → ЦП → «Виртуализация»); Hyper-V нет в Windows Home — нужна VMware Workstation Pro | глава 33, `CLAUDE.md` 7а |

Надписи в Windows и инструментах меняются с обновлениями. Если
у ученика они другие, сверь их скиллом `fact-check`.

## 5. Один шаг за раз

Дай **одно** действие и жди результата. Десять вариантов сразу
запутают его ещё сильнее. Не помогло — следующая догадка.

## 6. Чего не советовать никогда

- выключать антивирус целиком или навсегда;
- выключать Secure Boot или включать тестовую подпись на основном ПК —
  только в виртуальной машине, как в главе 29;
- запускать скачанные из интернета программы «для починки»;
- запускать незнакомые бинарники вне виртуальной машины (скилл
  `outside-practice`).

## 7. Если виновата глава

Устарела надпись, пропущен шаг, другая версия программы — значит,
дефект курса. Скажи честно: «это в главе неточно, а не ты ошибся».
Исправь главу точечно, а если причина в версии — сверь через `fact-check`.
Частую проблему добавь в главу как подсказку, чтобы следующий раз
её не было.
