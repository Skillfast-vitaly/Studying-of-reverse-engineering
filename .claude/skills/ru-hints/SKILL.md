# Русский подсказчик

Ученик читает ассемблер с английским A2. Подсказчик снимает барьер
мнемоники: наводишь мышку на строку — видишь по-русски, что делает
инструкция, что с флагами и **в каком разделе курса это объяснено**.
Он объясняет строку, но не программу, поэтому работу ученика не отнимает.

Что где лежит (`tools/hints/`):

| Файл | Что это |
|---|---|
| `hints_data.py` | база — **единственный источник правды** |
| `build_hints.py` | сборка и все проверки |
| `templates/` | шаблоны плагина IDA и скриптов Ghidra |
| `ida/ru_hints.py` | плагин для IDA Pro 9.2 — **собирается**, руками не править |
| `ghidra/RuHint*.java` | скрипты для Ghidra 12.1 — **собираются**, руками не править |
| `test/` | заглушки API Ghidra и тест «Java отвечает как Python» |
| `README.md` | установка и использование — для ученика |

## Добавить или поправить подсказку

1. Найди, где инструкция объяснена в курсе: номер раздела вида `10.4`
   или `П3.5`. Если нигде — оставь `ch=[]`, подсказчик честно скажет
   «в курсе пока не разбирали».
2. Пиши словами главы. Термины — как в `GLOSSARY.md` (скилл
   `glossary-term`): «знаковые/беззнаковые», «флаг переноса CF»,
   «летучие регистры». Поведение инструкции и флаги — только по
   документации Intel (страницы инструкций — в скилле `fact-check`).
3. Добавь запись в `ENTRIES` в `hints_data.py`. Поля описаны в шапке
   файла. `short` — до 46 знаков: он идёт в комментарий в коде.
   Семейства `jcc`, `setcc`, `cmovcc`, строковые (`movsb`…`cmpsq`)
   и дробные (`addss`…`maxpd`) разворачиваются сами — правь их
   в `CONDITIONS`, `SSE_OPS`, `STRING_OPS`.
4. Собери и проверь:

   ```bash
   python3 tools/hints/build_hints.py
   ```

   Скрипт собирает файлы и проверяет:
   - поля записей, отсутствие знака процента (окно IDA его съедает);
   - что разделы из `ch` существуют в `course/`;
   - логику плагина IDA на примерах;
   - что скрипты Ghidra компилируются и Java отвечает слово в слово
     как Python (нужен `javac`);
   - покрытие: какие инструкции учебных задач остались без подсказки
     (нужен кросс-компилятор, его ставит хук начала сессии).
5. Перечитай 3–4 готовые подсказки глазами ученика: по-русски ли,
   нет ли двойных скобок, совпадает ли перевод с именем (у `jnz` —
   «если не ноль», а не «если не равно»).
6. Закоммить вместе с собранными файлами `ida/` и `ghidra/` и запушь.

## Когда в главе появилась новая инструкция

Скилл `write-chapter` после главы прогоняет `build_hints.py`. Если
покрытие показало «нет подсказки» или раздел главы теперь объясняет
инструкцию, у которой стоит `ch=[]`, — обнови запись: ученик должен
попадать из IDA прямо в нужный раздел.

## Если ученик ставит подсказчик

Веди по `tools/hints/README.md`, по одному шагу. Пути на Windows:

- IDA 9.2: `%APPDATA%\Hex-Rays\IDA Pro\plugins\ru_hints.py`
  (папка пользователя IDA, сверено по `diskio.hpp` IDA SDK 9.2);
- Ghidra: `%USERPROFILE%\ghidra_scripts\` (папка скриптов
  пользователя, сверено по `GhidraScriptUtil.java` Ghidra 12.1.4).

Если не работает — скилл `troubleshoot`: точный текст из окна Output
(IDA) или Console (Ghidra), по-русски, одна причина за раз.
Чаще всего IDA не нашла Python 3 для IDAPython.

## Что ещё не проверено

Внутри настоящих IDA и Ghidra подсказчик не запускался: в облаке их нет.
Первое сообщение ученика о том, как он работает у него (всплывающая
подсказка, клавиши Ctrl+Alt+H/K/L, меню), запиши в `CLAUDE.md`,
раздел 7а, и сними эту оговорку здесь и в `README.md`.
