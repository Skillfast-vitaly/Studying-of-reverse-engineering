# Скилл курса

Ученик хочет, чтобы навыки работали сами (его просьба 10.10.2026).
Claude Code показывает модели описания всех скиллов, и модель вызывает
нужный сама. Поэтому главное в скилле — **описание**: по нему решается,
сработает он или нет. Второй уровень — хук `skill_router.py`: он
подсказывает скилл по словам ученика.

## Когда новый скилл нужен, а когда нет

Нужен, если есть повторяющаяся работа со своим порядком, своими
проверками или своими источниками, и её не покрывает ни один из
скиллов в `CLAUDE.md`, раздел 7. Не нужен «для количества»: лишний
скилл с похожим описанием мешает модели выбрать правильный. Если
работа близка к существующему скиллу — допиши раздел туда.

## Как написать

1. Папка `.claude/skills/имя/`, файл `SKILL.md`. Имя — латиницей
   через дефис (`verify-lang`). Скрипты — в `scripts/`, справочники —
   в `references/`.
2. Шапка:

   ```
   ---
   name: имя
   description: Что делает — одной фразой, словами курса. Когда
     использовать — перечисли ситуации и **слова ученика** в кавычках
     («не работает», «проверь меня»…), по которым его звать.
   ---
   ```

   Описание по-русски, конкретно, без «помогает с разным». Укажи
   и соседей: «для C — скилл verify-example».
3. Тело: зачем (одним абзацем, с привязкой к ученику — `CLAUDE.md`,
   раздел 1), порядок шагов, проверки, что можно и что нельзя, что не
   проверено. Каждый английский термин — с переводом.
4. Скрипты — рабочие в облаке **и** на ПК ученика (Git Bash): python
   ищи как `python3 → python → py`, кириллицу в Python читай и пиши
   в UTF-8 явно. Прогони скрипт на настоящих примерах до коммита.

## Как зарегистрировать

1. `CLAUDE.md`, раздел 7 — строка в нужную группу (сессия, писать
   курс, заниматься с учеником); раздел 6 — число скиллов.
2. `.claude/hooks/skill_router.py` — правило в `RULES`: шаблон по
   словам ученика и короткое «зачем». Добавь фразу в `TESTS`
   и прогони: `python3 .claude/hooks/skill_router.py --test`.
3. Если скиллом пользуется ученик — строка в README, раздел «Как
   заниматься со мной».
4. Коммит по-русски (почему нужен скилл) и пуш.

## Проверка, что скилл срабатывает

- Перечитай описание глазами модели: по каким словам ученика она его
  выберет? Есть ли эти слова в описании?
- Прогони тест маршрутизатора.
- В следующей сессии посмотри, вызвался ли скилл сам. Не вызвался —
  уточни описание и шаблон.
