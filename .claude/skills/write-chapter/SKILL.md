# Написание главы курса

Сначала прочитай `CLAUDE.md` — там профиль ученика и стандарты. Без этого
глава выйдет не под него.

## Порядок работы

### 1. Определи место главы

Открой `README.md`, найди первую главу со значком ⬜ или 🚧. Проверь по карте:
к какой части относится, что было в предыдущей главе, что будет в следующей.
Глава обязана опираться **только на уже написанное**.

### 2. Собери настоящие данные

Не выдумывай примеры. В контейнере есть кросс-компилятор:

```bash
x86_64-w64-mingw32-gcc -S -O0 -masm=intel -o - пример.c   # C -> ассемблер
x86_64-w64-mingw32-gcc -O2 -o прим.exe прим.c             # сборка .exe
objdump -d -M intel прим.o                                 # машинный код
objdump -p прим.exe                                        # структура PE
```

Все числа, адреса и листинги в главе должны быть получены так. Запустить
`.exe` в контейнере нельзя (нет wine) — логику проверяй сборкой того же
исходника под Linux.

### 3. Напиши главу

Структура обязательна:

```
# Глава N. Название

> **Часть X. Название части**
> Предыдущая глава: [ссылка]

Вступление: зачем глава, что ученик будет уметь после неё.

---

## N.1 … N.k — разделы

## Упражнения — 5–7 штук

## Что дальше — мостик к следующей главе

| навигация: предыдущая / оглавление / словарь / следующая |
```

Правила:

- объём 300–500 строк, подробно — ученик просил не жалеть букв;
- каждый английский термин с переводом (у ученика A2);
- связывай с прошлыми главами: «как мы выяснили в главе N»;
- Windows-first: никаких `objdump`/`gdb`/ELF в тексте для ученика;
- показывай, как тема связана с его целью — гипервизором.

**Важно:** длинный текст при записи обрезается. Пиши главу кусками по
120–180 строк во временные файлы и склеивай через `cat часть1 часть2 >> файл`.

### 4. Ответы к упражнениям

Допиши раздел `## Глава N. Название` в `ANSWERS.md`. Ответ — не просто
решение, а **ход рассуждения**: ученик должен понять метод, а не сверить
результат.

### 5. Проверь и опубликуй

```bash
python3 tools/check_course.py        # обязательно, должно быть чисто
```

Отметь главу как ✅ в `README.md`, закоммить по-русски (сообщение объясняет
*почему*, а не только *что*) и сразу запушь в ветку `claude/eager-lovelace-p96p9a`.

### 6. Сообщи ученику

Коротко: что за глава, что нового умеет, ссылка. Если глава закрывает часть
курса — напомни, что пора провести ревизию блока (скилл `review-block`).
