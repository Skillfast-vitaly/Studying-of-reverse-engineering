# Термин в словаре

У ученика английский A2, и словарь для него — опора (`CLAUDE.md`,
раздел 6). Правило курса: **один термин — одно введение**. Если одно
слово в двух главах переведено по-разному, он решит, что это два разных
понятия. Поэтому в `CLAUDE.md` прямо записано: volatile — «летучий»,
как в главе 12 и словаре, а не «изменчивый». 10.10.2026 проверка нашла
`strip`: в главе 14 «раздеть», а в главе 16 «ободрать» (исправлено).

## Формат записи

Из шапки `GLOSSARY.md`:

```
**English term** `[примерное произношение]` — перевод
Объяснение по-русски. Глава N.
```

- произношение — русскими буквами с ударением: `[дибáгер]`;
- несколько написаний — в одной записи: `**cross-reference, XREF**`;
- объяснение — одна-три строки простыми словами и номер главы, где
  термин введён;
- запись ставится в раздел своей темы: разделы идут по частям курса.

## Порядок

1. **Поищи, нет ли уже:**

   ```bash
   grep -n -i 'термин' GLOSSARY.md course/*.md
   ```

   Если есть — бери **тот же перевод**, что в словаре и в первой главе,
   где термин введён. Другое слово выбирай, только если старое
   неверно. Тогда исправь все места разом.
2. **Введи термин в главе один раз:** выделение, произношение, перевод.
   Дальше по курсу пиши так же, без нового введения: «как в главе N».
3. **Запиши в словарь** по формату выше.
4. **Прогони проверку:**

   ```bash
   python3 .claude/skills/glossary-term/scripts/check_glossary.py
   ```

   Скрипт показывает термины, записанные в словаре дважды (и с каким
   переводом), записи без произношения и термины, которые главы вводят
   с произношением, а в словаре их нет. По умолчанию выводятся первые 40,
   с ключом `--all` — все.

   «Проверь: разный перевод» ещё не значит ошибку. Омонимы законны:
   `flag` — флаг процессора и флаг CTF, `PE` — формат файла и бит CR0.
   А вот один смысл с двумя разными русскими словами — это ошибка,
   её исправляй.
5. Прогони `python3 tools/check_course.py`, закоммить и запушь.

## Что делать со списком «нет в словаре»

Список длинный: 10.10.2026 в нём было около сотни терминов. Добавлять
всё разом не нужно. Сначала возьми термины тех глав, по которым сейчас
идёт ученик, — их он ищет в словаре прямо сейчас. Остальное добавляй
при ревизии блока (скилл `review-block`).
