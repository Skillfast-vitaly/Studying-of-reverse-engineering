# Ревизия блока курса

Договорённость с учеником:

> Блок (= часть курса) закончен → перечитать целиком → прогнать через
> критерии → исправить найденное → только потом писать следующий блок.

Это не формальность. Первая же ревизия блока I нашла 7 реальных дефектов.

Сначала прочитай `CLAUDE.md` — критерии выводятся из профиля ученика.

## Порядок работы

### 1. Определи границы блока

По `README.md` найди, какие главы входят в законченную часть. Ревизуют
**только завершённый** блок: если в части не хватает глав, сначала допиши их.

### 2. Перечитай все главы блока целиком

Именно перечитай, а не просмотри по диагонали. Ценность ревизии — свежий
критический взгляд на то, что писалось по частям и в разное время.

### 3. Прогони автоматические проверки

```bash
python3 tools/check_course.py
```

Ловит битые ссылки, незакрытые блоки кода, слипшуюся вёрстку, остатки
Linux-инструментов, дубли от склейки, непокрытые ответами упражнения.

Дополнительно проверь глазами то, что скрипт не умеет:

- **нумерация глав в перекрёстных ссылках** — после перестроек карты курса
  ссылки вида «разберём в главе 7» часто устаревают;
- **устаревшие утверждения о структуре** («курс из пяти частей»);
- **обещания файлов, которых нет**.

### 4. Оцени по критериям ученика

| Критерий | Что проверяешь |
|---|---|
| Реально ли с нуля | Нет необъяснённых терминов, нет скачков |
| Английский A2 | Каждый термин переведён |
| Windows-first | Нет остатков Linux |
| Опора глав | Глава стоит только на предыдущих |
| Практика | Есть что потрогать руками, упражнения с ответами |
| Точность | Ноль фактических ошибок |
| Ведёт к цели | Видна связь с дорогой к гипервизору |
| Тон | Держит интерес, по-человечески |

### 5. Исправь найденное

Правки вноси точечно (Edit), а не переписыванием файлов — так не появится
новых склеек. После правок снова прогони `check_course.py`.

### 6. Закоммить и запушь

Сообщение коммита перечисляет найденные дефекты и объясняет, **почему**
каждый был проблемой именно для этого ученика.

### 7. Отчитайся ученику

Формат отчёта:

1. **Что было не так** — таблица дефектов с объяснением, чем это грозило ему
2. **Вердикт по критериям** — таблица с оценками
3. **Итог** — годен блок к прохождению или нет
4. **Честная оговорка** — это самопроверка, у неё есть предел; попроси
   отмечать места, где он споткнётся при чтении
5. **План дальше** — какой блок следующий

Не приукрашивай. Если блок слабый — так и скажи и переделай.
