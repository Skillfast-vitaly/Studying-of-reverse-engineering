# Конец сессии

Контейнер эфемерный: следующая сессия знает только то, что лежит
в репозитории. 10.10.2026 нашлась такая дыра: сессия wizardly-clarke
перенесла в главу 30 нужные куски, но не записала это в `CLAUDE.md`.
Там осталось «осталось сделать», и следующая сессия могла бы сделать
ту же работу второй раз. Поэтому у конца сессии есть свой порядок.

## 1. Ничего не потерять

```bash
git status --short                      # должно быть пусто
git log --oneline @{u}..HEAD            # незапушенные коммиты — тоже пусто
```

Если что-то осталось — закоммить по-русски (сообщение объясняет
*почему*) и запушь в ветку своей сессии.

## 2. Проверки

```bash
python3 tools/check_course.py
python3 tools/audit_refs.py
node .claude/skills/trainer-group/scripts/check_trainer.js   # если трогал тренажёр
```

## 3. Запись в CLAUDE.md, раздел 7а

Одна запись на сессию, коротко, но так, чтобы следующая сессия
продолжила без расспросов:

- дата и ветка сессии;
- **что сделано** — файлы и главное содержание;
- **что дальше** — следующий шаг по плану;
- **заявки:** если брал главу и не закончил, напиши, что заявка снята
  или что сделано в черновиках;
- **обрывы фильтром:** тема и шаг. Сам оборванный текст не пиши;
- **сверенные факты** — с датой и источником (скилл `fact-check`);
- **вопросы ученику, на которые ждём ответа** — чтобы `start-session`
  спросил их снова.

Если запись устарела (написано «осталось», а уже сделано), исправь её
сейчас. Это и есть дыра, найденная 10.10.2026.

## 4. Живые индикаторы

- README: ✅ у законченных глав и приложений;
- тренажёр: если менялся — опубликован в тот же артефакт, номер версии
  в `CLAUDE.md` поднят (скилл `trainer-group`);
- `PROGRESS.md`: итог занятия, если оно было (скилл `lesson`).

## 5. Влить в основную ветку — только с разрешения

Основная ветка — `claude/eager-lovelace-p96p9a` (`CLAUDE.md`, раздел 5).
Если закончен блок или сделано много, спроси ученика, можно ли влить.
Разрешение даётся **каждый раз заново**. Если он разрешил:

```bash
git fetch origin claude/eager-lovelace-p96p9a
git merge origin/claude/eager-lovelace-p96p9a      # сначала подтянуть основную к себе
python3 tools/check_course.py                      # после слияния — снова чисто?
git push origin HEAD:claude/eager-lovelace-p96p9a  # без --force
```

Если `push` отказал, значит, кто-то успел раньше. Повтори `fetch`
и `merge` и запушь снова. Принудительный пуш (`--force`) в основную
ветку запрещён.

## 6. Итог ученику

Коротко и по-человечески:

1. что сделано — 2–4 строки, без хешей и названий веток;
2. **один практический шаг** для него до следующей сессии: упражнение,
   режим тренажёра, задача;
3. один-два вопроса на понимание, обычным текстом;
4. если обещал что-то проверить или прислать — напомни, что ждёшь.
