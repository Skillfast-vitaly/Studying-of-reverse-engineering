# Что просят в вакансиях реверсеров

Выборка, собранная веб-поиском 10.10.2026. Это несколько вакансий,
а не статистика рынка. Обновляй раз в полгода или когда ученик выберет
профессию (глава 40.3). Ищи по общим профессиям: вирусный аналитик,
реверс-инженер, исследователь уязвимостей. Игровую тему не трогай:
на ней 10.10.2026 оборвался ответ.

| Требование | Где в курсе | Состояние |

## Часто, но не везде

| Требование | Где в курсе | Состояние |
|---|---|---|
| Python для скриптов и автоматизации анализа | П6 (10.10.2026): свои утилиты, IDAPython, PyGhidra | есть |
| C++ в дизассемблере: классы, `this`, таблицы виртуальных функций | — | **пробел**, а большинство программ Windows написано на C++ (цель 1 ученика) |
| сеть: протоколы, разбор трафика в Wireshark | глава 15 — только кто с кем соединяется (Procmon, TCPView) | **пробел** |
| упаковщики, обфускация, анти-отладка | главы 23–25, 19 — отложены (фильтр) | **пробел**, его спрашивают на собеседовании (таблица 40.4) |
| защиты от эксплуатации: ASLR, DEP, CFG | ASLR и DEP есть (главы 11, 13, 26, 32), CFG нет | частично |
| правила YARA (у вирусных аналитиков) | — | пробел, важен только для этой профессии |
| английский: документация и отчёты | П4, словарь, 40.7 | идёт, A2 — потолок для собеседования |
| Linux и ELF, ARM | — | осознанно вне курса (Windows-first) |

## Опыт

Вакансии для начинающих иногда просят «около двух лет опыта».
Без коммерческого опыта за начинающего говорят портфолио (40.5),
разборы задач, CTF и свой проект. Студенческие стажировки ищи
поиском в стране ученика ближе к делу: они меняются каждый год.
