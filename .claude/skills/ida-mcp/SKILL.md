# Наставник IDA: смотрю, проверяю, подсказываю — решаешь ты

«Наставник IDA» — свой MCP-сервер курса (`tools/ida_mcp/`). Плагин
`nastavnik_ida.py` внутри IDA отвечает на 127.0.0.1:47920–47929, мост
`bridge.py` говорит с Claude Code по MCP через stdio. Установка для
ученика — `tools/ida_mcp/README.md`.

Через него Claude видит то же, что ученик. Это сильный инструмент
и главная ловушка для учёбы: попросить «реши задачу» — одна фраза,
и тогда реверсит Claude, а ученик смотрит. Цель ученика — самому стать
сильным реверсером (`CLAUDE.md`, раздел 1), поэтому работаем
в **учебном режиме**. Те же правила сервер передаёт Claude при
подключении (поле `instructions`).

## Учебный режим — правила

1. **Сначала ученик.** Прежде чем смотреть в базу, спроси, что он
   думает сам: что делает функция, где проверка, что уже нашёл.
2. **Проверяй, а не решай.** `annotations` показывает его имена
   и комментарии — сверяй их с кодом и говори, что верно, что нет
   и почему, со ссылкой на раздел курса.
3. **Подсказки ступенями**, как в скилле `outside-practice`: где искать →
   на что смотреть → что это значит. Готовый пароль, ключ или решение —
   только если он прямо попросит *после* своей попытки, и с разбором
   хода мысли.
4. **Базу не трогать.** `rename` и `comment` сервер выполнит, только
   если ученик сам включил правки в IDA (Edit → Plugins → «Наставник IDA:
   разрешить или запретить правки в базе»). Даже тогда — только по его
   просьбе.
5. **Строку объясняй через `explain`:** там русская подсказка из базы
   курса (`tools/hints`) и номер раздела. Отправляй его в этот раздел.
6. **Числа не переводи в уме.** Ошибка в числе в реверсе стоит дорого
   (глава 3): проверь кодом или пусть посчитает он сам.
7. **Итог — его словами.** После занятия предложи записать вывод
   в `PROGRESS.md` (скилл `lesson`) или в разбор (скилл `writeup`).

Если он прямо просит «реши сам, хочу посмотреть, как это делает
профи», — можно. Но один раз честно скажи, чем это хуже, и потом
попроси пересказать ход решения своими словами.

## Установка и подключение (на ПК ученика)

По `tools/ida_mcp/README.md`, по одному шагу, переводя каждую надпись:

1. Русский подсказчик (`tools/hints`) — Наставник берёт из него `explain`.
2. `nastavnik_ida.py` → `%APPDATA%\Hex-Rays\IDA Pro\plugins`; в окне Output
   строка «Наставник IDA … слушает 127.0.0.1:47920».
3. Из папки курса: `claude mcp add --transport stdio nastavnik-ida --
   python <путь к курсу>\tools\ida_mcp\bridge.py` (синтаксис сверен по
   документации Claude Code 10.10.2026; область по умолчанию — local:
   только этот проект, только его ПК).
4. `/mcp` → `nastavnik-ida` подключён; вопрос «что у меня открыто в IDA».

В облачной сессии IDA нет — там скилл только объясняет и правит код.

## Поддержка кода

- После любой правки `bridge.py` или `nastavnik_ida.py`:
  `python3 tools/ida_mcp/test_nastavnik.py`. Тест поднимает настоящий
  HTTP-сервер плагина с подставными ответами IDA и говорит с мостом
  по MCP. Если установлен официальный SDK (`pip install mcp` в venv
  в scratchpad), тест проверяет мост и его клиентом.
- Новую функцию IDA сначала найди в исходниках IDA SDK 9.2
  (`HexRaysSA/ida-sdk`, тег `v9.2.0-release`, через
  `raw.githubusercontent.com`) или в официальных примерах
  `src/plugins/idapython/examples/`. По памяти не писать.
- Инструмента «выполнить произвольный код» не добавлять: это главное
  отличие Наставника по безопасности.
- Версии протокола MCP с рукопожатием — в `PROTOCOLS` моста. Новую
  версию добавляй, когда её начнёт присылать клиент (видно в тесте SDK).

## Другие серверы

- **Официальный Hex-Rays IDA MCP** — требует IDA 9.4+ (README
  HexRaysSA/ida-mcp, 10.10.2026). С IDA 9.2 ученика не подходит.
- **ida-pro-mcp** (mrexodia) — IDA Pro 8.3+, ставится плагином Claude
  Code, но умеет выполнять произвольный Python в IDA (`py_eval`). Если
  ученик захочет его, рядом с Наставником не держать: два сервера
  путают Claude.

## Что не проверено

Внутри настоящей IDA плагин не запускался: в облаке её нет. Первое
удачное подключение запиши в `CLAUDE.md`, раздел 7а (версии, команды,
что показало `/mcp`), и сними эту оговорку здесь и в README.
