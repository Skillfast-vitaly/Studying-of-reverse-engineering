# «Наставник IDA» — свой MCP-сервер курса для IDA Pro 9.2

MCP (Model Context Protocol `[модэл кóнтэкст прóутэкол]`, «протокол
контекста модели») — способ подключить программу к Claude. Наставник
подключает к Claude Code твою IDA: Claude видит то же, что и ты, —
функции, дизассемблер, псевдокод, строки, импорт. А ещё **твои
переименования и комментарии**, поэтому может проверить твою работу.

## Чем он лучше для тебя

Главное: он работает с твоей IDA. Официальный сервер Hex-Rays
требует более новую IDA (сверено по его README 10.10.2026):

| | Наставник IDA | Официальный сервер Hex-Rays |
|---|---|---|
| версия IDA | **9.2** (твоя) | 9.4 и новее |
| что поставить | только Python | Git, uv, IDA с idalib, Python 3.11+ |

Что сделано именно под тебя:

- инструкции объясняются **по-русски**, со ссылкой на раздел курса;
- **учебный режим**: менять твою базу можно, только если ты сам
  разрешишь это в IDA;
- команды «выполнить любой код» **нет вообще** — так безопаснее.

Честно о слабых местах: он проще официального. Например, в нём нет
работы без окна IDA и нет правки типов. Для учёбы этого и не нужно.

## Учебный режим

По умолчанию Claude через Наставника **только смотрит**. Так задумано:
реверсить учишься ты. Хорошие просьбы:

- «посмотри, где у меня курсор, и объясни эту строку»;
- «проверь, правильно ли я переименовал функции в main»;
- «я думаю, что проверка пароля тут — прав ли я?»;
- «дай подсказку, куда смотреть дальше, но не ответ».

Разрешить правки (переименовать, поставить комментарий) можно только
в самой IDA: меню **Edit → Plugins** («Правка → Плагины») →
«Наставник IDA: разрешить или запретить правки в базе». Тем же
пунктом правки запрещаются обратно.

## Установка

Сначала поставь русский подсказчик (`tools/hints/README.md`): Наставник
берёт объяснения инструкций из него.

### 1. Плагин в IDA

1. Нажми **Win+R**, впиши `%APPDATA%\Hex-Rays\IDA Pro\plugins` и нажми
   **Enter**. Если такой папки нет — создай `plugins`, как
   в инструкции к подсказчику.
2. Скопируй туда файл `tools\ida_mcp\nastavnik_ida.py`.
3. Перезапусти IDA и открой программу, например `01_strings.exe`.
4. В окне **Output** («вывод») должна появиться строка:
   «Наставник IDA 1.0 слушает 127.0.0.1:47920 (только этот компьютер).
   Учебный режим: правки в базе выключены».

`127.0.0.1` — адрес «этот же компьютер». Наставник не виден ни из
интернета, ни из твоей домашней сети.

### 2. Мост в Claude Code

Мост — это файл `tools\ida_mcp\bridge.py`. Claude Code сам запускает
его и через него говорит с IDA. Подключается одной командой
в терминале, из папки курса. Если курс лежит в `C:\reverse\course`
(так в главе 6), то так:

```
cd C:\reverse\course
claude mcp add --transport stdio nastavnik-ida -- python C:\reverse\course\tools\ida_mcp\bridge.py
```

Если курс лежит в другом месте, поменяй путь в обоих местах.
Сервер подключится только к этому проекту и только у тебя на ПК.

### 3. Проверка

1. IDA открыта с программой, плагин загружен (шаг 1).
2. Запусти `claude` в папке курса и набери `/mcp`: в списке должен быть
   `nastavnik-ida` с отметкой, что он подключён (connected).
3. Напиши: «посмотри, что у меня открыто в IDA». В ответе должны быть
   имя файла и число функций, как в окне **Functions** («функции»).

Если не работает — напиши мне точный текст ошибки (скилл `troubleshoot`).
Частые причины:

- нет строки «Наставник IDA … слушает» — плагин не в той папке
  или IDA не нашла Python 3;
- «IDA не отвечает» — IDA закрыта или программа в ней не открыта;
- `python` не найден — поставь Python 3 и отметь при установке пункт
  про PATH (переменная со списком папок, где Windows ищет программы).

## Что умеет (инструменты)

| Инструмент | Что делает |
|---|---|
| `status` | что открыто: версия IDA, файл, ImageBase, число функций |
| `current` | где твой курсор: адрес, строка, функция |
| `functions` | список функций, кого ты уже переименовал |
| `disasm` | дизассемблер функции или куска |
| `decompile` | псевдокод Hex-Rays, если декомпилятор есть |
| `xrefs_to` | кто ссылается на адрес |
| `strings`, `imports` | строки и импорт, как в окнах IDA |
| `annotations` | **твои** имена и комментарии в функции — для проверки |
| `read_bytes` | байты по адресу |
| `explain` | русская подсказка к инструкции и раздел курса |
| `rename`, `comment` | правки — только если ты разрешил их в IDA |

## Что проверено, а что нет

- **Проверено в облаке.** Мост работает по протоколу MCP. Его проверил
  мой тест и официальный клиент MCP SDK (версии 2.2.0 и 2.3.0):
  рукопожатие, список инструментов, вызовы. Проверены и сервер плагина
  с подставными ответами IDA, учебный режим, понятная ошибка, когда IDA
  выключена, и защита от запросов из браузера. Имена функций IDA сверены
  с исходниками IDA SDK 9.2 и официальными примерами Hex-Rays для 9.2.
- **Не проверено.** Внутри настоящей IDA плагин ещё не запускался:
  в облаке IDA нет. **Напиши мне, что получилось у тебя**, — поправим.
