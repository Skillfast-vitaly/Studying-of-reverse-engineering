# Заглушки API Ghidra

Не настоящая Ghidra. Здесь только те классы и методы, которыми пользуются
скрипты подсказчика, с теми же именами и пакетами, что в Ghidra 12.1.4
(сверено по исходникам, тег `Ghidra_12.1.4_build`). Нужны, чтобы
`build_hints.py` мог скомпилировать скрипты в облаке, где Ghidra нет.

Если скрипт начнёт звать новый метод Ghidra — добавь его сюда, сверив
имя и типы по исходникам Ghidra.
