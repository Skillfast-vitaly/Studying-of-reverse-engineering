# Русский подсказчик для IDA Pro 9.2 и Ghidra 12.1

Наводишь мышку на инструкцию (или нажимаешь клавишу) — и видишь по-русски:

```
jnz — jump if not zero, «прыгнуть, если не ноль»
Условный переход: прыгает, если не равно, то есть результат — не ноль
(ZF = 0); иначе выполнение идёт дальше. Обычно стоит сразу за cmp или
test (9.7). Другие имена той же инструкции: jne.
Флаги: не меняет; смотрит на ZF.
Где в курсе: 9.8.
```

В подсказке есть английская расшифровка с произношением, что делает
инструкция и что с флагами. И главное — **номер раздела курса**, где она
объяснена подробно. Если инструкцию в курсе ещё не разбирали, подсказчик
так и скажет.

Ещё он умеет одним нажатием расставить короткие русские комментарии
ко всей функции:

```
lea   rcx, [rbp+var_20]    ; рус: lea — считает адрес/формулу, в память не ходит (10.4)
call  strcmp               ; рус: call — вызов функции (адрес возврата → стек) (11.2)
test  eax, eax             ; рус: test — И без записи, только флаги (10.7)
jnz   short loc_140001590  ; рус: jnz — прыжок, если не ноль (9.8)
```

Твои собственные комментарии он не трогает и умеет убирать за собой.

> **Важно про учёбу.** Подсказчик — это словарь, а не решебник. Он
> объясняет, что делает *одна строка*, но не скажет, что делает
> *программа*. Это по-прежнему твоя работа. Попробуй сначала прочитать
> строку сам, а подсказку открывай, чтобы проверить себя.

## Установка в IDA Pro 9.2

1. Найди у себя файл `tools\hints\ida\ru_hints.py` — он лежит в папке
   курса, которую ты скачал с GitHub.
2. Нажми **Win+R**, впиши `%APPDATA%\Hex-Rays\IDA Pro` и нажми **Enter**.
   Откроется папка настроек IDA.
3. Если внутри нет папки `plugins` («плагины»), создай её: правая кнопка
   мыши → **Создать → Папку** → имя `plugins`.
4. Скопируй `ru_hints.py` в эту папку `plugins`.
5. Перезапусти IDA и открой любую программу, например `01_strings.exe`
   из задачи 01.
6. Внизу, в окне **Output** («вывод»), должна появиться строка
   «Русский подсказчик загружен…».

### Как пользоваться в IDA

| Что сделать | Как |
|---|---|
| подсказка к строке | навести мышку на строку с инструкцией в окне **IDA View** и подождать секунду |
| подробное объяснение в окне | щёлкнуть по строке и нажать **Ctrl+Alt+H** |
| русские комментарии ко всей функции | курсор внутри функции → **Ctrl+Alt+K** |
| убрать эти комментарии | **Ctrl+Alt+L** |
| выключить или включить всплывающие подсказки | меню **Edit → Plugins** («Правка → Плагины») → «Русский подсказчик: подсказки вкл/выкл» |

Все команды есть и в меню правой кнопки мыши → «Русский подсказчик».

**Если клавиши не срабатывают** — переключи раскладку на английскую
(**Alt+Shift** или **Win+Пробел**) или пользуйся меню.

**Если строки «загружен» в окне Output нет**, скопируй оттуда красный
текст и пришли мне. Чаще всего дело в том, что IDA не нашла Python 3:
плагин написан на Python (IDAPython). Разберём вместе, по одному шагу
(скилл `troubleshoot`).

## Установка в Ghidra 12.1

1. Найди у себя два файла: `tools\hints\ghidra\RuHintExplain.java`
   и `tools\hints\ghidra\RuHintComments.java`.
2. Нажми **Win+R**, впиши `%USERPROFILE%` и нажми **Enter** — откроется
   твоя личная папка. Создай в ней папку `ghidra_scripts` («скрипты
   Ghidra»), если её ещё нет. Ghidra сама ищет скрипты именно там.
3. Скопируй оба файла в `ghidra_scripts`.
4. Запусти Ghidra и открой программу в **CodeBrowser** («обозреватель
   кода»): двойной щелчок по программе в окне проекта.
5. Открой меню **Window → Script Manager** («Окно → Менеджер скриптов»).
   Слева найди раздел **Русский подсказчик**. Так Ghidra в первый раз
   увидит скрипты и сама их скомпилирует; после этого заработают клавиши
   и пункты меню.

### Как пользоваться в Ghidra

| Что сделать | Как |
|---|---|
| объяснить инструкцию | щёлкнуть по строке в окне **Listing** («листинг») → **Ctrl+Alt+H** или меню **Tools → Русский подсказчик → Объяснить инструкцию** |
| комментарии к функции | курсор внутри функции → **Ctrl+Alt+K** → выбрать «Добавить» или «Убрать» |

В Ghidra подсказка показывается в отдельном окне и дублируется в окне
**Console** («консоль»). Всплывающих подсказок при наведении мыши в Ghidra
нет: для них нужен полноценный плагин, а не скрипт.

## Что проверено, а что нет

Честно, как в главах курса:

- **Проверено.** Имена функций IDA сверены с исходниками IDA SDK 9.2
  (официальные примеры Hex-Rays для 9.2). Имена функций Ghidra сверены
  с исходниками Ghidra 12.1.4. Логика проверена в облаке: плагин IDA
  запускался с заглушками вместо модулей IDA. Скрипты Ghidra
  скомпилированы с заглушками её API, и Java ответила слово в слово
  как Python. На 62 993 настоящих инструкциях из учебных задач курса
  (собраны компилятором, `-O0` и `-O2`) база не знает ноль инструкций.
- **Не проверено.** Ни IDA, ни Ghidra в облаке нет, поэтому внутри
  настоящих программ подсказчик ещё не запускался. **Пришли мне, что
  увидишь**: работает ли подсказка при наведении мыши, клавиши, меню.
  Если что-то не так — поправим.

## Для тех, кто пишет курс

Источник правды — `hints_data.py`. Файлы в `ida/` и `ghidra/` собираются
из него и шаблонов в `templates/`, руками их не правят.

```bash
python3 tools/hints/build_hints.py          # собрать и проверить
python3 tools/hints/build_hints.py --check  # только проверить
```

На Windows вместо `python3` пиши `python`. Порядок работы, когда в главе
появилась новая инструкция, — в скилле `ru-hints`.
