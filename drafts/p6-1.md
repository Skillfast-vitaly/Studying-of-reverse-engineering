# Приложение П6. Python для реверсера

> **Приложения к курсу**
> Когда проходить: после [приложения П1](p1-si-pishem-sami.md)
> и [приложения П5](p5-ida-pro.md). Опирается на главы 3 (числа
> и байты), 5 (язык C), 8 (формат PE), 16–17 (разборы задач 1 и 2),
> 20 (своя виртуальная машина) и приложения П1 (биты и структуры)
> и П5 (IDA).

Брат, в П5 ты запустил первый скрипт в IDA и, наверное, заметил:
Python читается почти как C, только без точек с запятой и фигурных
скобок. Пора выучить его по-настоящему. Это рабочий язык реверсера:
на нём пишут скрипты для IDA и Ghidra, маленькие инструменты «на один
раз» и автоматизацию разбора. В вакансиях из главы 40 Python часто
стоит в требованиях рядом с IDA и языком C.

Учить с нуля не будем: C ты уже знаешь (глава 5, П1). Поэтому всё
приложение построено на сравнении «в C было так — в Python так».
И на твоих же задачах: числа из главы 3, заголовок PE из главы 8,
пароль под XOR из главы 17, байт-код из главы 20.

После приложения ты будешь уметь:

- ставить Python на Windows так, чтобы он работал и с IDA 9.2,
  и с Ghidra;
- считать в Python, как на калькуляторе реверсера: hex, маски, знак;
- переводить код с C на Python;
- работать с байтами: `bytes`, `int.from_bytes`, модуль `struct`;
- писать свои утилиты: паспорт файла PE, поиск строк, снятие XOR;
- видеть, что Python сам — стековая машина, как твоя из главы 20;
- писать скрипты для IDA и Ghidra, которые сами подписывают
  расшифрованные строки;
- раскладывать системный регистр на биты одной командой — это
  пригодится на дороге к гипервизору.

Приложение длинное, около 1300 строк. Проходи его **в три захода**
(между ними — хоть день перерыва):

1. **П6.1–П6.6** — установка, язык, байты;
2. **П6.7–П6.10** — свои инструменты: паспорт PE, строки, XOR;
3. **П6.11–П6.15** — Python внутри инструментов реверсера и на дороге
   к гипервизору.

Весь код я запускал настоящим Python 3.13, а задачи собирал тем же
компилятором, что в главах 16–20. Вывод программ у тебя будет таким же:
Python одинаково считает на Linux и на Windows. Скрипты для IDA
и Ghidra я проверил на подставных функциях с теми же именами, что
в IDA 9.2 и Ghidra 12.1, — в настоящих программах они ещё не
запускались. Если у тебя что-то пойдёт иначе — пришли мне вывод.

## П6.1. Зачем реверсеру Python

Причин три, по важности.

**1. Скрипты внутри инструментов.** IDA и Ghidra выполняют Python
(П5.12). Всё, что ты делаешь руками — переименовать, найти вызовы,
расшифровать строку, — можно поручить скрипту. На задаче 01 это
не нужно. А в программе на десять тысяч функций скрипт за секунду
делает то, на что руками уйдёт день.

**2. Свои инструменты за десять минут.** В главе 20 ты написал
дизассемблер байт-кода на C — около 50 строк: открыть файл, `strtol`,
`fseek`, `fread`, закрыть. На Python тот же инструмент занимает
около 20 строк (упражнение П6.5). Реверсер постоянно пишет такие
программы «на один раз»: разобрать формат, перебрать ключи, сравнить
два дампа. Python для этого и придуман: меньше обвязки, больше дела.

**3. Язык профессии.** Многие инструменты реверса написаны на Python
или дают к себе доступ из Python: библиотека `pefile` для разбора PE,
сами IDAPython и PyGhidra. Отчёты, проверки, разбор тысяч файлов
подряд — всё это обычно Python.

**Чего Python не умеет.** Скажу честно: сам гипервизор на Python
не напишешь. Гипервизор работает ниже ядра, там нет ни интерпретатора,
ни библиотек — только твой машинный код. Его ты будешь писать на C
и ассемблере (П1, П2). Python — это твоя мастерская *вокруг*:
калькулятор, разбор логов и дампов, скрипты для дизассемблера.
В разделе П6.14 ты напишешь в этой мастерской первый инструмент для
дороги к гипервизору.

## П6.2. Поставить Python на Windows

### Сначала проверь, может, он уже есть

Для скриптов курса Python, возможно, уже стоит (README, раздел «Курс
у тебя на ПК»). Открой **PowerShell** — синее окно, найди его через
«Пуск» — и набери:

```
python --version
```

Если ответ вида `Python 3.13.5` — Python есть, смотри на номер версии
ниже. Если ошибка или открылся Microsoft Store — Python не установлен.

### Какая версия нужна

Тут есть подвох: IDA и Ghidra понимают не любой Python.

| Кто | Какие версии | Откуда знаю |
|---|---|---|
| IDA 9.2 | 3.11–3.13 | поддержку 3.13 Hex-Rays добавила в IDA 9.0 SP1 (заметки к выпуску). О 3.14 и новее официальных сведений я не нашёл: IDA 9.2 вышла раньше, чем Python 3.14 |
| Ghidra 12.1.4 | 3.9–3.14 | файл `GettingStarted.md` в исходниках Ghidra |
| скрипты этого приложения | 3.10 и новее | проверено на 3.13 |

Вывод простой: **ставь Python 3.13** — он подходит всем. Самая новая
ветка сейчас 3.15 (её выход был назначен на 9 октября 2026 года), но
для IDA 9.2 и Ghidra 12.1 она слишком новая. Номера версий в программах
меняются с обновлениями: если у тебя IDA новее, проверь у себя, какой
Python она понимает.

### Как поставить

Сейчас официальный способ — **Python Install Manager** `[пáйтон
инстóл мэ́неджер]`, «установщик Python». Это маленькая программа,
которая ставит нужные версии Python и переключается между ними
(сверено по документации Python, октябрь 2026). Старый установщик
`.exe` с python.org ещё выпускают, но с версии 3.16 его не будет.

1. Открой **Microsoft Store**, найди **Python Install Manager**
   и нажми **Установить** (Install; в некоторых версиях Store кнопка
   называется «Получить» — Get). Тот же установщик есть на
   python.org/downloads.
2. Открой новое окно PowerShell и поставь нужную версию:

   ```
   py install 3.13
   ```

   При первой установке программа может спросить, добавить ли папку
   `%LocalAppData%\Python\bin` в **PATH** — список папок, где Windows
   ищет программы. Соглашайся: тогда команды вроде `python3.13`
   заработают в любом окне.
3. Проверь:

   ```
   py list
   python --version
   ```

   `py list` (list — «список») покажет все установленные версии.
   Если версий несколько, нужную выбирают так:
   `py -V:3.13 имя_скрипта.py`.

Если `py install` отвечает непонятной ошибкой, значит, команду `py`
занял старый запускатель от прежней установки Python. Это не страшно,
но разбирать удобнее вместе: пришли мне текст ошибки.

### Подружить Python и IDA

IDA сама не знает, какой Python у тебя стоит. Для этого рядом с ней
лежит программа **idapyswitch** («переключатель Python для IDA»). Открой
консоль в папке, куда установлена IDA, и запусти:

```
idapyswitch
```

Она найдёт все Python на компьютере и предложит выбрать один —
выбери 3.13. Если Windows скажет, что не хватает прав, запусти консоль
от имени администратора (правый щелчок → «Запуск от имени
администратора»). После этого перезапусти IDA и посмотри в окно
**Output**: при запуске там появляется строка о Python. Пришли мне её
— я сверю с тем, что написано здесь.

Ghidra ищет Python сама, когда её запускают особым способом — об этом
в разделе П6.13.

### Первая программа

Заведи папку `C:\reverse\work\py` для скриптов этого приложения.
В PowerShell:

```
mkdir C:\reverse\work\py
cd C:\reverse\work\py
notepad hello.py
```

Блокнот спросит, создать ли новый файл, — соглашайся. Впиши одну
строку и сохрани (Ctrl+S):

```python
print("Privet, brat!")
```

Запусти:

```
python hello.py
```

В окне появится `Privet, brat!`. Сравни с C из главы 5: там нужны были
`#include <stdio.h>`, функция `main`, точка с запятой, компилятор
и отдельный запуск `.exe`. Здесь — одна строка и сразу результат.
Python не собирает `.exe`: **интерпретатор** (как в главе 20 —
программа, которая выполняет команды одну за другой) читает твой файл
и выполняет его прямо сейчас.
