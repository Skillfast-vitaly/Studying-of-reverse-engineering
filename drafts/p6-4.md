
## П6.7. Файлы и аргументы командной строки

Второй заход начинается здесь. Теперь у тебя есть всё, чтобы писать
свои инструменты. Нужны ещё две вещи: читать файл и получать
аргументы из командной строки.

### Прочитать файл целиком

```python
with open(path, "rb") as f:
    data = f.read()
```

- `open(path, "rb")` — открыть файл, как `fopen` в главе 20. `"rb"`
  значит то же самое: читать как байты;
- `with … as f:` — «пока работаешь с файлом `f`». Когда отступ
  кончится, Python сам закроет файл, даже если внутри случилась
  ошибка. Забыть `fclose` здесь невозможно;
- `f.read()` — прочитать всё. В `data` окажется объект `bytes`
  со всем файлом.

Файл задачи весит 250 КБ, а памяти у тебя 32 ГБ. Поэтому реверсеры
обычно читают файл целиком и дальше берут из `data` срезы: это проще,
чем прыгать по файлу через `seek`.

### Аргументы: `sys.argv`

В главе 20 программа получала `argc` и `argv`. В Python всё то же
лежит в модуле `sys` (system, «система»):

- `sys.argv` — список слов командной строки, все строками.
  `sys.argv[0]` — имя скрипта, дальше — аргументы;
- `len(sys.argv)` — сколько слов, вместо `argc`;
- `sys.exit("текст")` — напечатать текст и выйти с кодом ошибки 1.

### Свой HxD за 15 строк

Первый инструмент — показать байты файла так, как это делает HxD
(глава 6). Файл `hexdump.py`:

```python
# hexdump.py — байты файла, как в HxD (глава 6)
import sys

if len(sys.argv) < 2:
    sys.exit("zapusk: python hexdump.py fail [smeshchenie] [skolko]  (v hex)")
path = sys.argv[1]
offset = int(sys.argv[2], 16) if len(sys.argv) > 2 else 0
size = int(sys.argv[3], 16) if len(sys.argv) > 3 else 0x40

with open(path, "rb") as f:
    data = f.read()

chunk = data[offset:offset + size]
for i in range(0, len(chunk), 16):
    row = chunk[i:i + 16]
    text = "".join(chr(b) if 0x20 <= b < 0x7F else "." for b in row)
    print(f"{offset + i:08X}  {row.hex(' '):<47}  {text}")
```

Новое здесь:

- `A if условие else B` — выбор в одну строку, как `условие ? A : B`
  в C. Смещение и размер необязательны: нет аргумента — берём
  `0` и `0x40`;
- `range(0, len(chunk), 16)` — числа от 0 с шагом 16: начало каждой
  строки дампа;
- `"".join(…)` — склеить буквы в одну строку. Печатный байт
  становится буквой, остальные — точкой, как в правой колонке HxD;
- `:<47` — ширина 47 с выравниванием влево: столько занимают
  16 байтов с пробелами.

Скопируй `01_strings.exe` из `C:\reverse\course\crackmes\build`
в `C:\reverse\work\py` и запусти:

```
python hexdump.py 01_strings.exe
```

```
00000000  4d 5a 90 00 03 00 00 00 04 00 00 00 ff ff 00 00  MZ..............
00000010  b8 00 00 00 00 00 00 00 40 00 00 00 00 00 00 00  ........@.......
00000020  00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00  ................
00000030  00 00 00 00 00 00 00 00 00 00 00 00 80 00 00 00  ................
```

`MZ` в начале, а по смещению `0x3C` — `80 00 00 00`: PE-заголовок
начинается на `0x80`. Это цепочка из раздела 8.3, только теперь
её показала твоя программа. Проверь:

```
python hexdump.py 01_strings.exe 80 20
```

```
00000080  50 45 00 00 64 86 13 00 94 73 ca 6a 00 34 03 00  PE..d....s.j.4..
00000090  7b 07 00 00 f0 00 26 00 0b 02 02 29 00 6e 00 00  {.....&....).n..
```

`PE\0\0`, `64 86` — машина `0x8664`, `13 00` — 19 секций, как
в главе 8. Байты `94 73 ca 6a` — время сборки, у твоего файла они
точно другие. Подпись и машина у тебя совпадут, а число секций
и остальные поля зависят от версии компилятора: в w64devkit она может
быть новее моей.

## П6.8. Проект: паспорт файла PE

Теперь соберём то, что в главе 8 делал PE-bear: заголовки, точку
входа, таблицу секций. Смещения полей — из главы 8 и документации
Microsoft «PE Format» (сверено по её исходнику, октябрь 2026).

Файл `pe_info.py`:

```python
# pe_info.py — паспорт файла PE, как вкладки PE-bear (глава 8)
import struct
import sys


def u16(data, off):
    return struct.unpack_from("<H", data, off)[0]


def u32(data, off):
    return struct.unpack_from("<I", data, off)[0]


def u64(data, off):
    return struct.unpack_from("<Q", data, off)[0]


def load(path):
    """Прочитать файл, разобрать заголовки, вернуть словарь."""
    with open(path, "rb") as f:
        data = f.read()
    if data[:2] != b"MZ":
        sys.exit("ne PE: v nachale net MZ")
    pe = u32(data, 0x3C)                  # e_lfanew (раздел 8.3)
    if data[pe:pe + 4] != b"PE\0\0":
        sys.exit("ne PE: net podpisi PE")
    fh = pe + 4                           # файловый заголовок, 20 байт
    opt = fh + 20                         # за ним — опциональный
    info = {
        "data": data,
        "machine": u16(data, fh),
        "nsections": u16(data, fh + 2),
        "magic": u16(data, opt),
        "entry": u32(data, opt + 16),
    }
    if info["magic"] == 0x20B:            # PE32+, 64 бита
        info["base"] = u64(data, opt + 24)
    else:                                 # PE32, 32 бита
        info["base"] = u32(data, opt + 28)
    table = opt + u16(data, fh + 16)      # таблица секций
    info["sections"] = []
    for i in range(info["nsections"]):
        e = table + 40 * i                # запись секции — 40 байт
        name = data[e:e + 8].rstrip(b"\0").decode("ascii", "replace")
        vsize, va, rsize, raw = struct.unpack_from("<IIII", data, e + 8)
        flags = u32(data, e + 36)
        info["sections"].append((name, vsize, va, rsize, raw, flags))
    return info


def rva_to_off(info, rva):
    """RVA -> смещение в файле (раздел 8.7). None, если в файле этого нет."""
    for name, vsize, va, rsize, raw, flags in info["sections"]:
        if va <= rva < va + max(vsize, rsize):
            if rva - va >= rsize:
                return None               # в памяти есть, в файле нет: .bss
            return raw + (rva - va)
    return None


def off_to_rva(info, off):
    """Смещение в файле -> (имя секции, RVA). None вне секций (заголовки)."""
    for name, vsize, va, rsize, raw, flags in info["sections"]:
        if raw <= off < raw + rsize:
            return name, va + (off - raw)
    return None


def rights(flags):
    return (("R" if flags & 0x40000000 else "-") +
            ("W" if flags & 0x80000000 else "-") +
            ("X" if flags & 0x20000000 else "-"))


def main():
    if len(sys.argv) < 2:
        sys.exit("zapusk: python pe_info.py fail.exe")
    info = load(sys.argv[1])
    base = info["base"]
    print(f"mashina  {info['machine']:X}")
    print(f"magic    {info['magic']:X}")
    print(f"baza     {base:X}")
    print(f"vhod     RVA {info['entry']:X} = adres {base + info['entry']:X}")
    print(f"sekciy   {info['nsections']}")
    print()
    print("imya      v pamyati  RVA       v faile   smeshch.  prava")
    for name, vsize, va, rsize, raw, flags in info["sections"]:
        print(f"{name:9} {vsize:<10X} {va:<9X} {rsize:<9X} {raw:<9X} {rights(flags)}")


if __name__ == "__main__":
    main()
```
